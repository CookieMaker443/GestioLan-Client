# MessageText

## Overview

The `MessageText` record provides a robust, flexible mechanism for handling messages and errors. It can encapsulate both known errors, identified through localization keys, and raw, unexpected error strings (for example, TLS-certificate exceptions caused by a local reverse proxy whose CA is not trusted by the JVM). This architectural pattern ensures that the application can always present visual feedback to the user, whether an issue has been mapped in advance or not.

---

## Tech Stack

* **Java version:** Java 16+ (required because `record` is a standard feature from this version).
* **Design pattern:** Static Factory Method (for safe, controlled instance creation).

---

## Project Structure

* `it.cookie.utils.network.user`: package containing utility classes for network and user-related operations, such as login messages and connection errors.

---

## Classes & Interfaces

### MessageText

* **Type:** Record
* **Package:** `it.cookie.utils.network.user`
* **Description:** An immutable container for a text message or error. It semantically distinguishes expected states, which can be localized through a `ResourceBundle`, from unexpected states, represented by native exceptions.

**Fields**

| Name | Type | Purpose |
| --- | --- | --- |
| `bundleKey` | `String` | `ResourceBundle` key used to retrieve the translation for a known error. |
| `rawMessage` | `String` | Raw error message generated by the JVM or an unhandled exception. |

**Methods**

| Signature | Parameters | Return type | Description |
| --- | --- | --- | --- |
| `known(String bundleKey)` | `bundleKey`: translation key for a known message | `MessageText` | Static factory method returning an instance containing only the localization key. |
| `unknown(String rawMessage)` | `rawMessage`: generic error string | `MessageText` | Static factory method returning an instance containing only the raw error message. |
| `isKnown()` | None | `boolean` | Checks whether the current instance represents a known error (`bundleKey` is not null). |

**Source code reference:**

```java
package it.cookie.utils.network.user;

/**
 * Represents a login error or a system message.
 * - "known": expected error, identified by a ResourceBundle key.
 * - "unknown": unexpected error, containing the raw message.
 */
public record MessageText(String bundleKey, String rawMessage) {

    public static MessageText known(String bundleKey) {
        return new MessageText(bundleKey, null);
    }

    public static MessageText unknown(String rawMessage) {
        return new MessageText(null, rawMessage);
    }

    public boolean isKnown() {
        return bundleKey != null;
    }
}
```

## Configuration

For `known` messages to work, configure a `ResourceBundle` (for example, `messages.properties`, `messages_it.properties`, and so on) containing the keys supplied to the record, such as `login.SERVER_TIMEOUT=The server is not responding`.

## Examples

### Usage flow

Create the record through the static factory methods `known()` and `unknown()`. This object-oriented design deterministically distinguishes an unhandled exception from a localization key. The key is subsequently resolved through a `ResourceBundle` to obtain the message in the appropriate language. When displaying or processing the message, check its kind with `isKnown()` and extract the appropriate string.

### Implementation snippet

The following example creates and uses both a known and an unknown error:

```java
import it.cookie.utils.network.user.MessageText;
import java.util.Locale;
import java.util.ResourceBundle;

public class ErrorHandlingExample {
    public static void main(String[] args) {
        // Initialize a hypothetical ResourceBundle for translations
        ResourceBundle bundle = ResourceBundle.getBundle("messages", Locale.getDefault());

        // 1. Create a known/handled error
        MessageText knownError = MessageText.known("login.SERVER_TIMEOUT");

        // 2. Create an unknown/raw error
        MessageText unknownError = MessageText.unknown("PKIX path building failed: unable to find valid certification path");

        String message1 = knownError.isKnown()
            ? bundle.getString(knownError.bundleKey())
            : knownError.rawMessage();
        // Example output: "The server took too long to respond. Please try again."
        System.out.println(message1);

        String message2 = unknownError.isKnown()
            ? bundle.getString(unknownError.bundleKey())
            : unknownError.rawMessage();
        // Example output: raw, untranslated error message
        System.out.println(message2);
    }
}
```
